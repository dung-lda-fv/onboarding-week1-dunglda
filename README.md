# Modular JavaScript To-Do List App

A simple, browser-based to-do list app using plain JavaScript and Material Design CSS.

## Features
- Add, edit, delete tasks
- Mark tasks as complete/incomplete
- Filter/search tasks
- Set due dates and priorities
- Responsive Material Design UI
- Tasks persist in browser localStorage

## Usage
1. Open `index.html` in your browser.
2. Add, edit, complete, or delete tasks using the UI.
3. Filter/search tasks using the search bar.

## Development
- Core logic: `logic.js`
- UI rendering and events: `ui.js`
- Storage: `storage.js`
- Styles: `style.css`
- Tests: `spec/addTask.spec.js` (run with `SpecRunner.html`)
